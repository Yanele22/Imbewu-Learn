# RoyalConnect Frontend

A React + Vite frontend prototype for the RoyalConnect concept.

## Run

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite.

## Current prototype

- Professional Royal Square-style public navigation
- Individuals / Business / Services / Claims mega-menu
- Responsive mobile navigation
- RoyalConnect landing page
- Login page with Guided Mode UI
- Customer dashboard shell
- Floating help button
- No real authentication or financial data yet
